# Elokuvahaku ja Tekijä

Repossa frontend lopputyö. Sovellus on elokuvahaku missä käyttäjä voi hakea elokuvia.
Tekijä Joni Hyypiö

## Idea

Käyttäjä syöttää elokuvan nimen mitä haluaa etsiä ja tuloksissa näkyy elokuvan nimi, kuva, ja lyhyt tittle elokuvasta.
